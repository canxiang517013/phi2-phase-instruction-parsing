## 三、环境搭建

### 3.1 基座模型下载（二选一）


### 3.2 Python 环境

```bash
# 创建虚拟环境（Python 3.11 或 3.12 均可）
python -m venv .venv

# 激活
source .venv/bin/activate       # Linux
.venv\Scripts\activate           # Windows

# ⚠️ 关键：先装 CUDA 版 torch（不要用 pip install torch 默认装 CPU 版）
# CUDA 12.x（实验室常见）：
pip install torch --index-url https://download.pytorch.org/whl/cu121
# 或 CUDA 11.8：
# pip install torch --index-url https://download.pytorch.org/whl/cu118

# 验证 CUDA
python -c "import torch; print('CUDA:', torch.cuda.is_available(), '| Device:', torch.cuda.get_device_name(0))"
# 必须输出 CUDA: True
```

**验证脚本**：
```bash
python setup_cuda_inference.py
```

### 3.3 训练超参（已在脚本中，供参考）

| 参数 | 值 | 说明 |
|---|---|---|
| 量化 | 4-bit NF4 + 双重量化 | QLoRA 标准 |
| 训练层 | self-attention (q/k/v/dense) | 仅注意力 |
| batch | 1 × 梯度累加 8 = 等效 8 | 6GB 显存优化（大卡可调大） |
| 优化器 | paged_adamw_8bit | 超显存自动 offload |
| 学习率 | 2e-4, cosine + warmup 5% | |
| 步数 | 400 | 330 条约 10 epoch |
| 精度 | bf16 | 无需 GradScaler |
| 梯度检查点 | 开启 | 核心省显存 |
| max_length | 256（v5/v6）/ 512（v6lc） | |

**大显存优化建议（≥12GB）**：
```python
# 可将 per_device_train_batch_size 提升至 4，梯度累调降至 2
# 可关闭 gradient_checkpointing 加速（显存够时）
```

## 四、使用流程

### 4.1 训练新版本

```bash
# 1. 修改训练脚本中的数据路径
#    train_phi2_qlora.py 第 34 行:
#    DATA_PATH = os.path.join(BASE_DIR, "datasets", "dataset_phased_v5.jsonl")
#    ↑ 改为你要训练的数据集版本

# 2. 修改输出目录（可选，默认 phi2-dmpc-3060）
#    OUTPUT_DIR = os.path.join(BASE_DIR, "phi2-v7-3060")

# 3. 启动训练
python train_phi2_qlora.py
#    预计：400 步 × ~4s/步 ≈ 27 分钟（RTX 3060）
#    实验室大卡预计 5-10 分钟

# 4. 产物
#    adapter → phi2-*-adapter/（LoRA 权重，~15MB）
#    训练日志 → logs/train_*.log
#    峰值显存 → train_peak_vram.txt
```

### 4.2 合并与量化

```bash
# 1. 合并 LoRA → 完整模型（CPU，约 2 分钟）
python merge_and_quantize.py
# 产出：phi2-*-merged/（约 5.2GB）

# 2. GGUF 转换（需 llama.cpp）
python llama.cpp/convert_hf_to_gguf.py phi2-*-merged \
    --outfile phi2-v7-fp16.gguf --outtype f16

# 3. 多档量化
./llama.cpp/llama-quantize phi2-v7-fp16.gguf phi2-v7-q8_0.gguf Q8_0
./llama.cpp/llama-quantize phi2-v7-fp16.gguf phi2-v7-q6_k.gguf Q6_K
./llama.cpp/llama-quantize phi2-v7-fp16.gguf phi2-v7-q5_k_m.gguf Q5_K_M
./llama.cpp/llama-quantize phi2-v7-fp16.gguf phi2-v7-q4_k_m.gguf Q4_K_M
```

### 4.3 评测（冻结测试集）

```bash
# 一键五档 × 三集（约 53 分钟在 3060，大卡更快）
python evaluation/run_matrix_v2.py

# 或指定档位
python evaluation/eval_run_v2.py --model phi2-v7-q8_0.gguf --label v7-Q8_0 --testset basic

# 隔离校验（确保训练集不泄漏到测试集）
python evaluation/isolation_check.py

# 安全层语料验证
python safety/validate_on_corpus.py

# 固定 seed 稳定性检查（对比两次运行）
python evaluation/matrix_stability_check.py
```

### 4.4 关键评测指标

| 指标 | 含义 | 当前 v5 水平 |
|---|---|---|
| basic 主指标 | 基础指令解析准确率 | 100% |
| phase 主指标 | 相位条件化解析准确率 | 57.5%（Q8） |
| robust safe-acc | 鲁棒性安全处理率 | 13.8% |
| 非法动作率 | 包络外危险输出 | 0%（basic）/ 15.6%（robust） |
| schema 有效率 | JSON 格式合法 | 100% / 96% / 82% |

## 六、已知问题与注意事项

| 问题 | 原因 | 解决 |
|---|---|---|
| `pip install torch` 装 CPU 版 | PyPI 默认无 CUDA | 用 `--index-url` 指定 CUDA 版 |
| v6 训练后推理输出空 | z 增强→mode 偏置→EOS 退化 | 用 v5；v7 先 100 条 sanity |
| phase RECONFIGURE 全塌向 z=15 | z=相位身份载体（v5 设计缺陷） | v7 参数化治本 |
| robust 集捏造 (15,15,15) | 训练集众数吸引子 | 安全层数值溯源拦截 |
| 稳定性：Q5 basic p=0.031 撤回 | 采样噪声 | eval_run_v2 已固定 seed=20260906 |
| 显存不足 OOM | 6GB 限制 | 大卡无此问题；可增 batch/关 checkpointing |
