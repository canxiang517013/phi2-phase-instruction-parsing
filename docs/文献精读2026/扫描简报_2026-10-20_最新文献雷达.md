## B. 快查项（不精读，但需登记）

1. **PACE: Phase-Aware Chunk Execution for Robot Policies with Action Chunking**（arXiv 2606.00537，v3 2026-09-27，被引 9）
   "phase"指操作轨迹的运动学阶段（接近/抓取/切换），训练无关的测试期执行地平线选择；RoboTwin2.0 57.8%→64.2%，实机 ALOHA/Franka 成功率 50.7%→70.4%。
   **判定**：领域不同（VLA/扩散策略的操作任务），与 PA-MoE 一起构成 Related Work 术语辨析段的第二个引用；无主张冲突。
2. **WIUCAS"端侧大模型无人机搜救"新闻 = LMUCS 原班工作**（国科温州研究院帅建伟团队；AST Vol. 177, 2026, Art. 112949；Jetson Xavier NX；解析准确率 94.68%；代码 wp19991/LMUCS）
   **判定**：已在 Novelty Matrix [P3]，非新威胁；该新闻页可作为其系统细节（YOLOv11+MiDaS 17FPS、时间尺度分离架构）的补充引证来源。
3. **Do LLM-derived graph priors improve multi-agent coordination?**（arXiv 2604.17191，Gupta/Kannan/Prasanna，2026-04-19）
   LLM 从各智能体自然语言观测摘要推断协调图先验，喂给 GNN-MARL；MPE 四场景；自称"first quantitative evidence"；**小至 1.5B 的模型就够生成先验**。
   **判定**：LLM×MARL 相邻工作（refs_2026 的 LMAC/TodyComm 之外）；其"1.5B 足够生成语义结构"结论支持我们端侧小模型语义能力主张，可在讨论中引用；不入必比清单。
4. **LLM-Centric Agentic AI for UAV Swarms**（arXiv 2607.09756，2026-07）——综述/立场类，写 Related Work 时作背景引用候选，暂不精读。
5. **Defense-in-Depth at the Perception-Reasoning Interface**（arXiv 2610.03319，2026-10）——LLM 集群安全方向，与我们安全层叙事相邻但角度为对抗安全；登记备查。
6. **RALLY**（arXiv 2507.01378，2025-07）——LLM 语义推理+MARL 集群导航，早于 refs_2026 收录线（2026-01+），概念上与我们最近的历史工作；**建议补入 Novelty Matrix 备查行**（其"角色自适应+语义/MARL 分层"与我们元控制器叙事有修辞重叠，未比较过）。
7. **Ferrag et al., LLM and AI Agents for Autonomous Systems（43 页综述, 2026）**——含 SwarmChain（UAV 集群协同 LLM 推理系统）等系统条目；写 Related Work 的填充材料。

## C. 结论与行动项

1. **核心新颖性未失守**：本轮扫描（含"mission phase / phase-aware"定向撞车检查）未发现任何工作触及"相位语义作为云-边协议 + 量化档位×能力维度边界 + 断连 TTL 协议化"的组合。空白仍在，但——
2. **"phase"术语正在快速拥挤**：ICML 2026（PA-MoE，agentic RL 路由）与机器人执行（PACE）已在各自领域把 phase-aware 做成标题词。行动：① 12 月底 arXiv 占位不可再拖；② Related Work 增加 phase 术语辨析段（PA-MoE+PACE，把撞车转化为"概念家族+层级差异"论证）；③ 我们题目用 "Phase Semantics / Phase Protocol"（语义/协议层）而非泛化的 "Phase-Aware"（已有题目方案恰好规避）。
3. **端侧小 LLM 上机赛道加速**：LMUCS（AST 2026）→ SkyAgent（2026-08）→ 各机构新闻（2026-07）——b 方向（端侧解析）独占性窗口在收窄。行动：E3 规则基线与 LMUCS 复现（P0 清单）优先级不变；写作时把差异锚定在"相位条件化"。
4. **三条现成外部论据入库**（写作用）：裸 LLM 不可靠（WoD）→ 安全层必要性；token 与质量无关（WoD）→ 压缩无损论证（G4 佐证）；1.5B 足够生成语义结构（graph priors）→ 端侧语义能力主张。
5. **一个工程技巧待验证**：SkyAgent 的 Oracle 代理训练（训练期用确定性代理替换慢速 LLM，评估期换真 LLM）——检查我们 v7 训练是否已等效处理，未处理则纳入。
