## 一、系统概述

从 2v2 扩展到 3v3（红×3 + 蓝×3 = 6 机），增加以下核心能力：

| 能力 | 2v2 现状 | 3v3 目标 |
|---|---|---|
| 无人机数量 | 4 | 6 |
| 对抗场景 | 追逃（单一） | 追逃 + 区域攻防 + 护航（三场景） |
| 协同策略 | 独立追击/规避 | 质心围捕 / 分散规避 / 编队护航 |
| 裁判系统 | 距离判定胜负 | 实时评分 + 多条件胜负 + 回合制 |
| 通信 | 队内共享相位流 | 队内相位 + 机间协同消息 |
| MAPPO 桥接 | 预留接口 | 实际对接（相位驱动训练） |

### 2.2 通信量预算

| 信道 | 消息大小 | 频率 | 带宽 |
|---|---|---|---|
| 相位流（每队） | ~15 token | 0.2 Hz | ~30 B/s |
| 心跳（每队） | ~10 B | 1 Hz | ~10 B/s |
| NL 指令（每机） | ~50 B | 按需 | 可忽略 |
| 机间协同 | ~100 B | 0.5 Hz | ~50 B/s |

## 三、对抗博弈算法

### 3.1 协同策略设计

#### 红队（追击方）— 质心围捕策略

```
输入：蓝队质心 B = (bx, by)，红队各机位置 R_i
输出：每机追击目标 T_i

策略：
  1. 计算蓝队质心 B
  2. 计算包围圈半径 r = max(capture_radius * 2, dist(R_1, B))
  3. 每机分配包围角度 θ_i = 2πi/3 + phase_offset
  4. 目标 T_i = B + r * (cos θ_i, sin θ_i)
  5. 收缩：r 随时间递减（r = r_0 * exp(-t/τ)，τ=60s）
```

#### 蓝队（规避方）— 分散规避策略

```
输入：红队质心 R，蓝队各机位置 B_i，安全区 S
输出：每机规避目标 T_i

策略：
  1. 计算红队威胁向量 V = B_centroid - R（远离红队）
  2. 若 dist(B_centroid, S) < safe_radius：到达安全区，HOLD
  3. 否则：
     - B_1（领机）：飞向安全区 S
     - B_2, B_3：在领机方向 ±45° 分散规避（增大追击难度）
```

#### 护航场景（可选第三场景）

```
红队护送高价值目标 V 从 A 到 B
蓝队试图拦截 V
红队：V 周围 120° 间隔护航编队
蓝队：选择红队防线最薄弱角度突击
胜负：V 到达 B → 红胜；V 被拦截 → 蓝胜
```

### 3.3 MAPPO 桥接接口

```python
# bridge_node.py — MAPPO ↔ 部署层桥接
class MAPPOBridge(Node):
    """将 MAPPO 训练决策桥接到部署层相位信号"""

    # 订阅 MAPPO 动作
    /mappo/action  → {"team": "red", "drone": 0, "action": [vx, vy, vz]}

    # 转换为相位并发布
    def action_to_phase(self, team, drone_id, velocity):
        # 速度向量 → 目标位置 → 相位字符串
        target = self.predict_target(drone_id, velocity)
        phase = f"PURSUE@({target[0]:.0f},{target[1]:.0f})"
        self.publish_phase(team, phase)

    # 接收部署层反馈（训练数据）
    /deployment/feedback → {"episode": 1, "reward": 0.85, "success": true}
```

## 四、裁判系统升级

### 4.1 六机状态同步

```python
class Referee3v3(Node):
    """3v3 对抗裁判（支持 6 机状态同步）"""

    def __init__(self):
        # 订阅 6 机位置（NED → ENU + 世界偏移）
        self.drone_positions = [[0,0,0]] * 6
        self.world_offsets = {
            0: (0, 0),      1: (5, 0),      2: (-5, 0),     # Red
            3: (60, 60),    4: (65, 60),    5: (55, 60),    # Blue
        }

        # 实时评分
        self.score = {
            'red': 0.0, 'blue': 0.0,
            'red_captures': 0, 'blue_escapes': 0,
            'time_elapsed': 0.0,
        }

    def evaluate(self):
        """1Hz 评估循环"""
        # 1. 更新距离矩阵
        dist_matrix = self.compute_all_distances()

        # 2. 捕获判定（任一红蓝距离 < capture_radius）
        for r_idx in RED_TEAM:
            for b_idx in BLUE_TEAM:
                if dist_matrix[r_idx][b_idx] < CAPTURE_RADIUS:
                    self.score['red'] += 10
                    self.score['red_captures'] += 1
                    self.disable_drone(b_idx)  # 蓝机被捕获

        # 3. 安全区判定
        blue_safe = all(self.in_safe_zone(i) for i in alive_blue)
        if blue_safe:
            self.score['blue'] += 10
            self.game_over('blue_wins', 'all blue reached safe zone')

        # 4. 全灭判定
        if not any(self.is_alive(i) for i in BLUE_TEAM):
            self.game_over('red_wins', 'all blue captured')

        # 5. 超时判定
        if self.time_elapsed > TIME_LIMIT:
            winner = 'blue' if alive_blue > 0 else 'draw'
            self.game_over(winner, 'timeout')
```
