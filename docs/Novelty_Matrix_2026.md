## 二、逐篇一句话卡片（详版证据见各代理报告，存 docs/文献精读2026/）

- **Dong LLM-MATD3**：LLM 做高层博弈任务规划→嵌入向量→MATD3 机动决策；纯算法层，无系统/通信/端侧视野（摘要级）。
- **PKEG**：地面站 30B MoE INT4 + 知识图谱约束生成原子战术指令 JSON；**3.5 节四层确定性校验是卖点**；带宽压缩与机载 LLM 均列为未来工作。
- **LMUCS**：Qwen2.5-0.5B Q4 GGUF（352MB）+ Jetson Xavier NX + Ollama 跑指令解析，YOLO+MiDaS 感知，DJI Tello 实机；38k 双语数据集开源；**端侧小模型解析的直接竞品基线**。
- **CAIC**：共享信道排队延迟下的拥塞感知意图通信；预测轨迹→128 维意图向量；**实证陈旧消息比不通信更有害**（我们 TTL 设计的同源动机引证）。
- **LieQ**：奇异值熵几何代理预测层重要性，2-bit 预算内闭式分配 4-bit 保护层；无能力维度分析、无机器人应用。

## 三、不可再写首创的点（写作红线）

1. **"端侧小模型做无人机指令解析"**——LMUCS 已做（0.5B Q4 实机）。我们只能写"相位条件化的端侧解析"并引用对比。
2. **"LLM 输出的外置确定性安全层"**——PKEG 的四层校验（schema/物理/一致性）已发表为卖点。我们的安全层只能作为系统组件呈现，其差异化子点是**分轴数值溯源**（输出数值必须来自指令/相位上下文，PKEG 无此机制），不可笼统称首创安全层。
3. **"SLM 量化的层敏感性/部署边界"**——LieQ（层维度）与 LMUCS（两档+设备边界）各有份额。
4. **"陈旧消息比无消息更有害"作为动机发现**——CAIC 已在 MARL 通信中实证；我们应引用并将其从"发现"改为"在云-边指令链路上的协议化应对（TTL/降级）"。

## 四、仍然成立的差异化定位（无撞车，可作贡献主张）

1. **相位信号作为云-边语义瓶颈的形式化与因果验证**：五篇皆无（CAIC 最近但为同构向量、无云边异构链路、无相位语法/压缩收益量化；我们有 G3 词数匹配对照、G4 压缩收益 +55pp、G5 随机相位对照的因果链）。
2. **量化档位 × 能力维度的部署边界**：basic 全档稳 / phase Q4 悬崖 / robust 与量化无关的维度结构（LieQ 是层维度、LMUCS 是两档总体精度，均无能力维度拆解）。
3. **相位条件化的评测方法学**（冻结 600 条 + 六指标 + 隔离校验 + 配对统计 + 七组因果消融 G1-G7）。
4. **通信受限的显式协议设计**（timestamp+TTL+安全悬停降级 + 故障注入 pilot）：CAIC 是隐式学习策略，无断连场景、无协议化 TTL。
5. **云-边分工的定量证据**（G7：长样本端侧重训修长上下文但 basic -17pp → 压缩应放云端）。
