## 4. 问题清单（重构动机）

| # | 问题 | 证据 | 影响 |
|---|---|---|---|
| P1 | 权重产物命名无版本语义 | `phi2-dmpc-adapter` 实为 v5 | 迭代 v7 时必然冲突 |
| P2 | 目录名携带硬件信息 | `phi2-dmpc-3060` | 换 4090 训练后语义失效 |
| P3 | 共享库靠 `sys.path.insert` 散装引用 | 9 处 hack | 移动任一文件即断 |
| P4 | 路径/超参硬编码在脚本顶部 | `ADAPTER_DIR`/`DATA_PATH` ×13 处 | 改配置要改代码 |
| P5 | 数据集命名前缀不统一 | `dataset_phased_v5` vs `dataset_v6lc` | 版本检索困难 |
| P6 | 无版本控制 | 无 `.git/` | 重构无回滚保护 |
| P7 | 生成物与源码混放 | log/tar.gz/checkpoint 与代码平级 | 目录噪音 |
| P8 | 评测目录内生成器/评测器/分析器混层 | `evaluation/` 一级平铺 9 个 py | 职责不清 |
| P9 | **3v3 对抗部署层缺失** | 无 ROS 代码 | 需按新架构占位接入 |
| P10 | **迁移包不完整，评测链当前即断裂** | `eval_run_v2.py:62`/`run_matrix_v2.py:27`/`p0_deep_dive.py:22` import 未迁移的 `eval_run.py`；`gen_causal.py:41`/`gen_g7_trainset.py:30,33`/`gen_testset_v2.py:46` import 未迁移的 `gen_testset.py`；`run_comm_pilot.py:25` import 未迁移的 `phase_fault_proxy.py` | 六指标评测/矩阵/生成器/通信 pilot **在新机上无法运行**（训练与合并链路完好，已实测）。需从原机器补齐 3 个 v1 模块，或在重构中将公共函数收编入 `phi2_common` |

## 5. 待迁移占位（原机器存在、本机未迁移）

按迁移指南 §1.4 明确「不需迁移」但 3v3 对抗必需：`px4_ws/`（ROS2 工作区）、AirSim 桥、`phase-aware-llm-meta-controller/`（师兄上游仓库，建议以 git submodule 或 vendor 引入）。这些进入目标架构 `ros2_ws/` 的占位目录，见《03_目标架构》。
