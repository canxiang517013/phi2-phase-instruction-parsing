# 3D 训练优化版成果（2026-10-22 第二轮）

本目录是主机端提供的**优化版** `training_3d_bundle.zip` 在实验室服务器（RTX 4090）上的完整复现：
原始包 CRC 正常、内部 `SHA256SUMS.txt` 10/10 校验通过；代码未做任何修改。

## 1. 优化版相对旧版的关键改动（主机端）

- 编队几何修正（就近象限重排 `[0,2,3,1]`，leader 起点 z=40→目标 z=45，高度上限 100 m）
- leader 运动课程：前 400 集静止；第 401 集起每集第 150 步开始移动，速度 6→8→10 m/s（1400/2000 集后）
- 回报归一化（running std，clip 100）+ 速度匹配项 `0.08·||v_i − v_leader||²`
- PPO：4 epochs、minibatch 256、关闭 value clip、熵系数 0.002（上限 0.003）
- action log_std 初始 -0.5；Critic 128→256
- 新增 `actor_best.pth` + `best_checkpoint.json`（按滚动 100 集成功率/跟随误差选优）
- episode 长度 500→600；Ollama 预热（修复首次咨询冷加载超时）
