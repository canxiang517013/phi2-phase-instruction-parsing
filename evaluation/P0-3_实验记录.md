## 2. 因果结论（任务书口径："phase 收益来自哪里"）

1. **phase 标签的收益来自信息压缩到训练分布内的短格式**：同信息同长度的结构化文本（G3）几乎无效（~10%），只有短标签（G4 55%）或按长格式重训（G7 G2 57%）有效。收益不是"结构化"，是"分布内"。
2. **phase 语义被真实使用**（G5 随机标签 63-70% 被跟随），模型不是把标签当无意义 token——G5 同时给出系统风险边界：标签错则动作错（结合 G6 100% 捏造，错误 phase 的高层指令会一路畅通到输出）。
3. **能力 vs 分布之辨有定量答案**：2.7B 并非"长文本能力不足"（G7 修复到 57%），是训练分布不匹配；但在同等训练预算（400 步）下，加入 27% 长样本使 basic 显著回退 17pp——端侧小模型在固定容量/预算下无法免费兼得，**这正是 phase 作为云-边语义瓶颈的架构价值**：把长上下文处理留给云端，端侧只消费压缩后的标签即可保住精度与延迟。
4. G3 的 15%（G7 后）说明长格式学习是**格式特异性**的（散文训练不迁移到 key:value），进一步支持"固定一种清晰接口"（任务书第 4 周要求）。

## 4. 对论文的贡献点

- 创新点 1（phase 语义压缩）的因果证据链闭合：G2/G3/G4/G5/G7 五组对照构成"压缩收益来自分布内短格式 + 语义真实使用 + 可修复但有代价"的完整论证。
- 端-云分工的定量依据（G7 的 basic -17pp 显著回退）：算力受限端侧不应承担长上下文解析。
- G6 + P0-2 的越界回声 → P0-4 确定性安全层的需求论证（两处独立证据）。
